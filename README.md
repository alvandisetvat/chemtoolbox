# جعبه ابزار شیمی — شبیه‌سازی سه‌بعدی آزمایش‌های کتاب‌های شیمی (استان همدان)

سایت ایستا (بدون سرور و بدون نیاز به build): هر آزمایش یک پوشه است، یک هستهٔ مشترک ظاهر و رفتار را یک‌دست می‌کند، و هر آزمایش داخل iframe جداگانه اجرا می‌شود تا خطای یکی بقیه را خراب نکند.

## راه‌اندازی (۳ دستور)
```bash
node tools/fetch-vendor.mjs      # یک‌بار: دانلود three.js و فونت وزیرمتن داخل vendor/ (نیاز به اینترنت)
node tools/build-index.mjs       # اعتبارسنجی شناسنامه‌ها و ساخت فهرست
node tools/serve.mjs             # http://localhost:8080
```
اگر npm در دسترس نیست: `node tools/fetch-vendor.mjs --registry <آدرس آینهٔ npm>`. یا دستی: فایل‌های `build/three.module.js`، `examples/jsm/controls/OrbitControls.js` و `examples/jsm/environments/RoomEnvironment.js` از بستهٔ **three@0.160.0** را به‌ترتیب در `vendor/three/three.module.js`، `vendor/three/addons/controls/` و `vendor/three/addons/environments/` بگذارید.

> نسخهٔ تحویلی پوشهٔ `vendor/` را **خالی** دارد (من در محیط ساخت به اینترنت دسترسی نداشتم). تا آن را پر نکنید آزمایش‌ها باز نمی‌شوند و صفحه پیام راهنما نشان می‌دهد.

## ساختار
```
index.html            پورتال (فهرست، فیلتر، نمایشگر)
player.html           صفحهٔ اجرای یک آزمایش (?e=<شناسه>)
playground.html       محیط تست دبیران (شناسنامه، خطاها، آزمون خودکار، چک‌لیست)
sw.js                 کش آفلاین
core/                 هستهٔ مشترک (فقط یکپارچه‌ساز تغییر دهد)
  api.js              تنها دروازهٔ آزمایش‌ها به هسته
  chemistry.js        فرهنگ مشترک رنگ مواد
experiments/<id>/     meta.json + experiment.js
experiments/planned.json   آزمایش‌های برنامه‌ریزی‌شده (کارت «به‌زودی»)
tools/                serve (server-lib)، build-index، fetch-vendor، check-names، smoke
docs/                 راهنمای دبیران، API، پرامپت، چک‌لیست، تقسیم‌کار
vendor/               three.js و فونت (با fetch-vendor پر می‌شود)
```

## افزودن آزمایش
دبیر: `docs/teacher-guide.md` و `docs/prompt.md`. یکپارچه‌ساز: پوشه را در `experiments/` بگذارد، سپس
```bash
node tools/check-names.mjs       # نام تعریف‌نشده/import اشتباه (نیاز: npm i -D typescript)
node tools/build-index.mjs       # اعتبارسنجی + ساخت فهرست و فهرست کش
node tools/smoke.mjs             # اجرای خودکار همهٔ مراحل در مرورگر (نیاز: npm i -D playwright)
```
شناسه‌های `experiments/planned.json` که پوشه‌شان ساخته شد خودکار از «به‌زودی» به «آماده» تبدیل می‌شوند.

## استقرار
فقط پوشه را (بدون `docs/` و `tools/` اگر نمی‌خواهید) روی هر میزبان ایستا بگذارید: Cloudflare Pages (دستور build خالی، پوشهٔ خروجی = ریشه)، آروان‌کلاد/هر هاست ایرانی یا nginx. قبل از بارگذاری `node tools/build-index.mjs` را اجرا کنید تا `experiments/index.json` و `precache.json` به‌روز باشند.
- برای Service Worker (کار آفلاین) سایت باید با **HTTPS** سرو شود.
- نوع MIME فایل `.js` باید `text/javascript` و `.woff2` باید `font/woff2` باشد (در میزبان‌های معمول پیش‌فرض است).
- هر بار آزمایش جدید اضافه شد دوباره build و بارگذاری کنید؛ کش کاربران خودکار به‌روز می‌شود.

## حقوق
در شناسنامهٔ کتاب‌ها اقتباس و بازنشر شکل‌ها و متن بدون مجوز سازمان پژوهش و برنامه‌ریزی آموزشی منع شده است؛ تصاویر کتاب را کپی نکنید و برای انتشار کشوری مجوز بگیرید. نام تهیه‌کننده هر آزمایش در صفحه و روی تابلوی صحنه نمایش داده می‌شود.
