# تقسیم‌کار پیشنهادی

واحد تقسیم: یک «کاوش کنید». فهرست زیر از مرور متن سه کتاب (چاپ ۱۴۰۵) به‌دست آمده؛ قبل از تقسیم، با کتاب چاپی تطبیق دهید (ممکن است یکی دو مورد جا افتاده باشد).
ستون «قطعهٔ جدید» یعنی پیش از شروع، یکپارچه‌ساز باید آن قطعه را یک بار در `core/` بسازد.

**ترتیب پیشنهادی:** نخست «solution»ها (سبک‌ترین، با قطعه‌های موجود)، همزمان ساخت قطعه‌های جدید توسط یکپارچه‌ساز، سپس «apparatus» و «concept».

## مفاهیم پیشنهادی برای شبیه‌سازی (از بخش‌های «با هم بیندیشیم» و «خود را بیازمایید»)
پیشنهادهای زیر از مرور کتاب‌ها و آشنایی با سرفصل‌هاست؛ شناسهٔ دقیق صفحه را مجری مشخص کند.

| پایه | مفهوم | چرا سه‌بعدی/تعاملی؟ |
|---|---|---|
| ۱۰ | طیف نشری خطی اتم و مدل بور | انتقال الکترون و رنگ خط‌ها |
| ۱۰ | ایزوتوپ‌ها و واپاشی | شمارش ذره‌ها و نیمه‌عمر |
| ۱۰ | حجم مولی و رفتار گازها | فشار/دما/حجم با ذره‌ها |
| ۱۰ | قطبیت مولکول و کشیده‌شدن باریکهٔ آب | میدان الکتریکی و جهت‌گیری مولکول |
| ۱۰ | انحلال مواد یونی/مولکولی در آب و نمودار انحلال‌پذیری | سطح ذره‌ای |
| ۱۱ | ظرفیت گرمایی و گرماسنجی | دما–زمان |
| ۱۱ | سرعت واکنش و نمودار مول–زمان | برخورد ذره‌ها و کاتالیزگر |
| ۱۲ | صابون و مایسل | ساختار آب‌دوست/آب‌گریز |
| ۱۲ | اسید/باز، pH و ثابت تعادل | سطح ذره‌ای |
| ۱۲ | سلول گالوانی و emf | حرکت الکترون/یون؛ در کتاب آزمایش عملی ندارد |
| ۱۲ | الکترولیز و آبکاری | همان |
| ۱۲ | تعادل و اصل لوشاتلیه (هابر) | تغییر شرایط و جابه‌جایی تعادل |
| ۱۲ | ساختار الماس، گرافیت و یخ | چرخش سه‌بعدی بلور |

نوع `concept` به قطعه‌های جدید و رویکرد دیگری (ذره‌ای) نیاز دارد؛ بهتر است بعد از پایان آزمایش‌های عملی، با مجری باتجربه‌تر شروع شود.
