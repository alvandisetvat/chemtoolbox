# پرامپت آماده برای ساخت یک آزمایش

**پیوست کنید (همه را):**
1. `docs/LAB-API.md`
2. `experiments/iron-ions/experiment.js` و `experiments/iron-ions/meta.json` (نمونهٔ مرجع)
3. `experiments/_template/experiment.js` (قالب خالی)
4. `core/chemistry.js` (فرهنگ مواد)
5. عکس یا PDF صفحهٔ کتاب آزمایش

**متن پرامپت** (کروشه‌ها را پر کنید):

```
تو یک برنامه‌نویس جاوااسکریپت و آشنا به شیمی دبیرستان هستی. می‌خواهم برای طرح «جعبه ابزار شیمی» یک شبیه‌سازی سه‌بعدی از آزمایش کتاب بسازی.

آزمایش: [نام کاوش، مثل: پاک‌کنندگی صابون در آب‌های گوناگون]
کتاب و صفحه: [شیمی ۳، صفحهٔ ۹]   پایه: [دوازدهم]   فصل: [۱]
تهیه‌کننده: [نام و نام خانوادگی]
فایل پیوست‌شده: صفحهٔ کتاب (مواد، مراحل، پرسش‌ها)

وظیفه:
۱. فقط با API موجود در LAB-API.md کار کن و فقط از '../../core/api.js' import کن.
   ساختار و سبک کد را مثل experiments/iron-ions/experiment.js بنویس.
۲. مراحل را به ترتیب و با واژه‌های کتاب بیاور (tag و text هر مرحله مطابق کتاب).
   اگر کاوش چند آزمایش دارد، هر کدام یک تب باشد.
۳. رنگ مواد و رسوب‌ها فقط از core/chemistry.js. اگر ماده‌ای لازم است که آنجا نیست،
   آن را کنار کد در بخشی به نام «موارد لازم برای یکپارچه‌ساز» بنویس (نام، رنگ پودر، رنگ محلول، رنگ رسوب)؛
   خودت رنگ جدید در کد نساز.
۴. مشاهده‌ها، معادلهٔ موازنه‌شده (با حالت فیزیکی) و نتیجه را در مرحلهٔ پاسخ با ansStep و eq بیاور.
   پاسخ‌ها باید از نظر علمی دقیق باشند؛ اگر مطمئن نیستی، علامت «[بررسی شود]» بگذار.
۵. اگر برای آزمایش قطعه‌ای لازم است که در بخش «محدودیت‌ها»ی LAB-API.md نیست (مثل بشر یا دماسنج)،
   نساز؛ فهرستش را بده و فقط بخش‌هایی را که با قطعه‌های موجود ممکن است بنویس.
۶. هیچ آدرس اینترنتی، fetch، eval یا localStorage ننویس. متن‌ها فارسی و ارقام با fa().

خروجی:
- فایل meta.json کامل (همهٔ فیلدها، category و difficulty را خودت پیشنهاد بده)
- فایل experiment.js کامل
- فهرست «موارد لازم برای یکپارچه‌ساز»
- یک پاراگراف: چه چیزی در شبیه‌سازی ساده‌سازی شده و چرا
```

**بعد از دریافت پاسخ:**
1. پوشهٔ `experiments/<id>/` بسازید و دو فایل را بگذارید.
2. `node tools/serve.mjs` ← `http://localhost:8080/playground.html?e=<id>`
3. «آزمون خودکار» را بزنید و خطاها را به همان گفتگو برگردانید تا اصلاح شود.
4. چک‌لیست را کامل کنید و پوشه را برای یکپارچه‌ساز بفرستید.
